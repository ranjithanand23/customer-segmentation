# Customer Segmentation using Machine Learning

A machine learning project focused on customer segmentation and behavioral analysis using K-Means clustering, RFM analysis, PCA visualization, and exploratory data analysis techniques.

---

## Overview

This project analyzes customer purchasing behavior and groups customers into meaningful segments using unsupervised machine learning techniques. The workflow includes data preprocessing, feature engineering, clustering analysis, dimensionality reduction, and visual interpretation of customer groups.

The project applies both:

- **RFM-based clustering**
- **Feature-based clustering**

to better understand customer behavior patterns and purchasing trends.

---

## Features

- Exploratory Data Analysis (EDA)
- Customer behavioral analysis
- RFM (Recency, Frequency, Monetary) analysis
- Feature engineering
- K-Means clustering
- Elbow Method for optimal cluster selection
- PCA-based 2D cluster visualization
- Correlation analysis (Pearson & Spearman)
- Cluster comparison and interpretation
